# JayLL — AI Research Lab

Playable Three.js portfolio preview, built with Vite and the original portfolio content.

Run local:

```bash
npm install
npm run dev
```

Build with `npm run build`, verify migration with `npm test`, and preview the static output with `npm run preview`.

Desktop: **WASD / arrows** to move, **drag** to look, **Shift** to run, **E** near a workstation to interact. Mobile visitors can browse all projects and the gallery directly. The original résumé and prompts pages retain their URLs; the terminal lives at `/legacy/`.

See [preview notes and architecture](docs/ai-research-lab.md).

## Legacy Easter Eggs & Secret Commands

Try typing these into the terminal:
- `sudo`: Try to gain root access.
- `rm -rf`: See what happens when you try to delete everything.
- `theme [name]`: Switch themes (amber, dracula, cyberpunk).
