# Project icon sources

- `pondie-tab.png`: Chrome Web Store listing's 128px Open Graph icon for [Pondie Tab](https://chromewebstore.google.com/detail/pondie-tab-cozy-frog-comp/anomdkjhpfojkpoebfpiohlpeidhcaeb), retrieved 2026-10-26. The listing identifies Jay's published extension.
- `tiengnoi.png`: `/icon-192.png` from [tiengnoi.online](https://tiengnoi.online/), retrieved 2026-10-26. It is the product site's own application icon.
- All SVG files in [`chat-app/src/project-icons/`](../chat-app/src/project-icons/) were created for this portfolio, based on each project's described function. They are illustrative marks, not claimed official logos.

The linked Windhawk mod, Hugging Face model, PyPI package, and GitHub repositories did not expose a project-specific icon suitable for this catalog. Their platform favicons were deliberately not used as project logos.
